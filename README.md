A deterministic Node 22 program (standard library only, offline) that draws one page of world news for Thursday, 19 November 2026 as a single 1024x1024 PNG.

Run it with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`, then check `out/entry.png`.
